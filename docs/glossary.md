# Glossary

- **AICTE:** All India Council for Technical Education.
- **APH:** Approval Process Handbook; the applicable version and official source must be confirmed for each workflow.
- **EoA:** Extension of Approval.
- **OCR:** Optical Character Recognition, which extracts text from images/scanned pages.
- **Structured extraction:** Mapping document text into predefined fields.
- **Validation rule:** A deterministic check against an approved requirement.
- **Finding:** A recorded result that requires attention, review or resolution.
- **Source verification:** A comparison against an authorized external or official source.
- **Simulated verification:** A prototype/mock response, not an official source response.
- **Compliance Memory Graph:** Linked representation of an institution's applications, documents, claims, rules and review history.
- **Compliance drift:** A meaningful change across current and prior evidence or applicable rules.
- **Provenance:** The source and processing history behind a field, finding or decision.
- **Human-in-the-loop:** An authorized person reviews evidence and makes decisions reserved for them.
- **False positive:** A system flag that turns out not to represent a real issue.
- **Document version:** A specific immutable submitted file and its metadata.
- **Audit event:** A time-stamped record of a significant action or change.
